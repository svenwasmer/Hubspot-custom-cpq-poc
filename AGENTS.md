# Project

Name: hs-cms-cli-tests

Description: POC for testing HubSpot Pages API to create custom landing pages from a template that will be filled with external data with the goal to create a custom Configure Price Quote (CPQ) solution.

Requirements and Scope: see 'project-scope.md'. read it before starting any new feature or if the task is unclear.

No write access to:
.env

## Git Process

- For every new feature, create a feature branch before making changes.
- Merge branches only with `--no-ff`.
- Do not commit changes unless the user explicitly asks for a commit or gives approval first.
- If a commit would be useful but has not been requested, ask for approval before committing.
- If a feature branch was commited and merged into main ask for permission to do a 'git push' for github sync

## Backlog Catalogue

- `backlog.md` is the place to find ideas to work on and to store new ideas.
- The backlog is managed as a markdown todo list.
- `backlog.md` has two sections:
  - `Up next`
  - `Completed`
- `Completed` is a historical log of all completed tasks.
- `Up next` is where all new ideas sit.
- Whenever a task is complete, move it to the `Completed` section.
